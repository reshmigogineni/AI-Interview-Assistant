# 🤖 AI Interview Assistant

An AI-powered web application designed to help students practice mock interviews, improve technical knowledge, and assess their interview performance.

## 📌 Project Overview

The AI Interview Assistant provides an interactive platform where students can practice technical interviews and receive AI-generated feedback on their answers. The platform aims to help students identify their strengths and areas for improvement before attending real interviews.

## ✨ Features

- **AI-Powered Interviews:** Generate technical interview questions using AI.
- **Mock Interview Sessions:** Practice interviews based on difficulty levels.
- **Answer Evaluation:** Analyze answers and provide scores and feedback.
- **Resume Support:** Upload resumes for interview preparation.
- **Performance Assessment:** Evaluate relevance, technical accuracy, clarity, and completeness.
- **Web-Based Interface:** Interact with the application through a user-friendly interface.

## 🚀 Getting Started

### Prerequisites

Install the following tools before running the project:

- Python
- Node.js and npm
- Git

### Backend Setup

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd AI-Interview-Assistant
   ```

3. Create and activate a Python virtual environment.

4. Install backend dependencies:

   ```bash
   pip install -r backend/requirements.txt
   ```

5. Configure the required environment variables in a `.env` file. Add your Gemini API key and other required configuration values.

6. Start the FastAPI server using the appropriate entry point for your backend setup.

### Frontend Setup

1. Open a new terminal.
2. Navigate to the frontend directory:

   ```bash
   cd frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## 🔐 Security

- API keys and environment variables must not be committed to GitHub.
- Keep your `.env` file private.
- Do not upload personal or confidential resume information.
